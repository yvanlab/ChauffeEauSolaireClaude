Color coding in browser:
- INFO logs  = Light blue background
- OK logs    = Light green background
- WARN logs  = Light yellow background
- ERROR logs = Light red background

Auto-refresh: Updates every 3 seconds
Auto-scroll: Automatically scrolls to newest log
Clear button: Removes all logs (requires confirmation)

============================================================
NOTES:

1. All logs are visible in BOTH serial monitor AND web interface
2. Last 100 log entries are kept in memory
3. Logs are cleared on ESP32 restart (not persistent)
4. Serial monitor shows real-time output
5. Web interface auto-refreshes every 3 seconds

============================================================

TO RUN THIS ON YOUR ESP32:

1. Edit data/wifi_config.json with your WiFi credentials
2. Run: pio run --target upload
3. Run: pio run --target uploadfs
4. Connect serial monitor: pio device monitor
5. Access web: http://chauffeSpa.local
