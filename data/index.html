🔗 API REST - Points d'accès HTTP

Liste complète des endpoints HTTP disponibles sur l'ESP32 pour l'intégration et le débogage.

Endpoint Méthode Description Format réponse
/ GET Page web principale HTML
/data GET État complet du système (Capteurs + Config active) JSON
/history GET Historique des températures (dernières 24h) JSON
/sensors GET Liste des capteurs DS18B20 détectés JSON
/system/info GET Informations système (version, mémoire, etc.) JSON
/config POST Mise à jour de la configuration température JSON
/pump POST Contrôle manuel de la pompe JSON
/sensors/mapping POST Configuration des rôles des capteurs JSON
/wifi POST Configuration WiFi JSON
/wifi/scan GET Scan des réseaux WiFi disponibles JSON
/wifi/scan/start GET Démarrage du scan WiFi (asynchrone) Plain text
/logs GET Récupération des journaux système JSON
/logs/clear POST Effacement des journaux Plain text
/restart POST Redémarrage de l'ESP32 Plain text
/update/firmware POST Téléversement du firmware (OTA) Plain text
/update/filesystem POST Téléversement du système de fichiers (OTA) Plain text

💡 Exemples d'utilisation:

Données capteurs: curl http://esp32.local/data
Liste capteurs: curl http://esp32.local/sensors
Info système: curl http://esp32.local/system/info
Contrôle pompe: curl -X POST http://esp32.local/pump -d "state=on"
