📋 LANCEMENT RAPIDE
═══════════════════

  1. Double-cliquez sur:  launch_simulator.bat

  2. Ouvrez votre navigateur à:  http://localhost:8080

  3. Pour arrêter: Appuyez sur Ctrl+C dans le terminal

📊 GRAPHIQUE 24H
═══════════════════

  Le simulateur génère automatiquement un historique réaliste
  de 24 heures avec des cycles journaliers:

  • Air:      18-28°C (suit le cycle jour/nuit)
  • Spa:      28-35°C (se réchauffe l'après-midi)
  • Panneaux: 15-50°C (pic vers 13h, suit le soleil)

  • Aucune bibliothèque externe requise

═══════════════════

  • Idéal pour faire des démonstrations


🐛 EN CAS DE PROBLÈME
═══════════════════

  Port déjà utilisé ?
    → Modifiez le port dans web_simulator.py (ligne finale)
    → run_simulator(8081)  # Changez 8080 en 8081

  Python non trouvé ?
    → Installez Python: https://www.python.org/downloads/
    → Cochez "Add Python to PATH" lors de l'installation

  Page ne charge pas ?
    → Vérifiez que le terminal montre "Server running"
    → Essayez http://127.0.0.1:8080
    → Videz le cache navigateur (Ctrl+F5)
